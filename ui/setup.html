🧩 Two different things you can add

Worth thirty seconds, because the next two sections do different jobs and the words look alike.

⚙️ An engine

The software that runs an AI. HIVE Limited is one. llama.cpp and vLLM are others. Install one of those to race against.

🧠 A model

The AI itself — its knowledge and personality, in a file. Qwen3-1.7B is one. Every engine needs a model to run.

A race is two engines running the same model. That is the whole idea: hold the AI fixed, change only the software underneath, and the difference you see is the engine.

⚙️ Add a rival engine

Don't take our word for anything. Install another piece of AI software and watch it answer the same question, on your computer, next to ours.

llama.cpprecommended

The most popular way to run AI at home. Runs the same model as HIVE, in the same 4-bit size — so the race is about the engine, not the file.

~5 min to build · needs the CUDA Toolkit

vLLM

The standard engine for AI servers. Heavier: it brings PyTorch and several GB of NVIDIA libraries with it.

~10 min · several GB download

      I'd rather type it myself, or want a different model
      

        
The menu, from your terminal:

        
~/hive-limited/setup/download_models.sh

        
Or any Qwen3 model from HuggingFace by name:

        
~/hive-limited/setup/download_models.sh Qwen/Qwen3-14B

        
Only Qwen3 works — this build ships kernels for that design only.

      

    


    

      Why each model downloads twice
      

        
HIVE and vLLM read one file format; llama.cpp reads another called GGUF. It is
           the same AI packaged two ways, so the script fetches both.

        
This matters more than it sounds. Both lanes have to run the same model or the
           race means nothing — and a mismatch would not look like an error, it would look like a
           perfectly normal result with a meaningless number. So the arena hands the chosen model
           to every engine rather than letting each pick its own file, and if a model is missing
           one of the two formats the dropdown says HIVE only and tells you which engine
           cannot run it, before you race rather than after.

      

    

  


  
  

    
Something went wrong?

    

      Click whichever matches. Copy-paste fixes.
    


    
“curl: command not found”
      
Install it, then paste the line from Step 2 again:

      
sudo apt update && sudo apt install -y curl


    
“No NVIDIA graphics driver found”
      

      
On Windows: install the normal driver from
         nvidia.com/drivers — in Windows itself,
         not inside Ubuntu — then close and reopen the Ubuntu window.

      
You do not need the big “CUDA Toolkit”.

      
On Ubuntu: sudo ubuntu-drivers autoinstall then reboot.


    
The download stopped partway
      
Run the same line again. It keeps what it already downloaded and
      carries on from there.


    
“Permission denied”
      
chmod +x ~/hive-limited/start.sh


    
The page won't open in my browser
      
Check the terminal still shows it running. If you closed that window
      the program stopped — start it again:

      
~/hive-limited/start.sh
